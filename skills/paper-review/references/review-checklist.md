# review-checklist.md — 4维度审查清单

> **可替换模板**：paper-review 各阶段共用审查清单——
> 阶段1（去AI审查）、阶段2（研讨角色检查基准）、阶段5（复查评分依据）。
> 审查论文时逐项核对；未通过项按 P0/P1/P2 记入发现清单。

---

## 维度1：去AI化检查

- [ ] 无 Tier1 词汇（delve, landscape, tapestry, paradigm shift, leverage, harness, navigate, realm, embark, myriad, plethora, multifaceted, groundbreaking, revolutionize, synergy, ecosystem, resonate, streamline）
- [ ] 无过度对仗结构（"从X到Y"、"不仅X更Y"密集出现）
- [ ] 无空洞总结（"综上所述"、"总而言之"每段使用）
- [ ] 无AI高频词过度使用（核心/关键/本质/范式）
- [ ] 句式长短交错（非全段长句或全段短句）
- [ ] 无排比式列举（三个并列"从X到Y"）
- [ ] **注意**：「文献[N] XXX」逐篇引用平行句式是学报标准风格，**不属于AI写作问题**

> Tier1 词汇残留与结构问题计数用于计算去AI评分（见 convergence-criteria.md）。

## 维度2：学术规范检查

- [ ] 引用准确性：描述与原文一致，不过度延伸
- [ ] 引用格式：GB/T 7714 统一（[J]期刊 [M]专著 [C]会议 [R]报告 [D]学位论文 [S]标准 [N]报纸）
- [ ] 术语首次出现有英文全称和缩写
- [ ] 图表标题中英文对照
- [ ] 参考文献编号连续无遗漏

> 引用准确性问题（描述与原文不符、过度延伸）一律记 **P0**。

## 维度3：写作质量检查

- [ ] 段落结构：每段有明确主题句
- [ ] 过渡自然：段间逻辑连贯
- [ ] 标点规范：中文全角、英文/数字半角
- [ ] 无语法错误
- [ ] 无错别字

## 维度4：结构完整性检查

- [ ] 各节字数在目标范围内
- [ ] 三段模式（定义与机理→引用印证→意义总结）
- [ ] 无跨节引用（各节自包含）
- [ ] 引言→正文→结论逻辑完整

---

## 严重度分级对照（与 merge_findings.py 一致）

| 级别 | 含义 | 典型问题 |
|------|------|---------|
| **P0** | 必须修改 | 事实错误、引用错误（与原文不符/过度延伸）、逻辑断裂、过度声明 |
| **P1** | 重要修改 | AI痕迹（Tier1词汇/对仗/排比/空洞总结）、结构问题（跨节引用/字数失衡）、术语错误 |
| **P2** | 建议修改 | 措辞润色、语句打磨、标点、错别字 |
