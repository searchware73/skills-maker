## 共同豁免清单（1a 配置卡下发，任何席位不得上报）

- 学位文体（长铺垫/章节小结）——doctype=thesis 时
- 期刊模板格式（栏目体例/页眉页脚）
- pandoc/PDF 转换伪影（以 `{run_dir}/conversion_audit.md` 丢失清单为准）
- 「文献[N] XXX」逐篇引用平行句式（学报标准风格）
- doctype 豁免要素（见 doctype-criteria.md；结构类仅 S1 在「类型适配说明」注明）

## S1 EIC/统筹 — 结构与类型适配（垄断）

- [ ] 核心贡献清晰：标题/摘要/引言/结论四处口径一致
- [ ] 结构闭环：引言承诺 → 正文兑现 → 结论回收，无断链
- [ ] 按 doctype 必备要素逐项核查（applied_criteria.required），缺失按表定级
- [ ] 豁免要素缺失 → 报告头「类型适配说明」一句话注明，不计 P0/P1/P2
- [ ] 合规清单组核查（保密/伦理/AI披露/数据可得性，按类型绑定）
- [ ] 各节字数在目标范围内；无跨节引用（各节自包含）
- [ ] 决议档位建议 + 理由（Accept/Minor/Major/Reject）

## S2 方法论 — 设计与统计

- [ ] 每个论点有充分证据支撑；因果推理无跳跃；无循环论证
- [ ] 统计方法恰当：检验选择/样本量/效应量/显著性表述（如 Cohen's dz 报告规范）
- [ ] 实验公平：基线选取合理、消融充分、对照可比
- [ ] 结论强度 ≤ 证据强度（超范围即报，声称级归 S6 定性）
- [ ] 可复现性：实现细节/超参数/数据划分充分（按 doctype 置换规则）
- [ ] 数值疑点**转交 S7**，不自行复算

## S3 领域 — 文献与术语（格式已脚本化）

- [ ] bib_lint.md（Step 0 产物）error 条目复核；**不重复手工查格式**
- [ ] 引用语义核对：支撑核心论断的引用逐条对照原文（联网/原文），
      描述不符或过度延伸 → **P0**
- [ ] 领域重要文献无遗漏；增量定位诚实（与最近邻工作的差异说清）
- [ ] 术语与领域共识一致；跨领域映射合理
- [ ] 外部事实类指控提交前完成文献级核验（否则按撤回规则处理）

## S4 写作编辑 — 语言与体例

- [ ] 连续相同句式/对仗排比/空洞总结（语言级 AI 痕迹，与阶段2重叠时以阶段2为准）
- [ ] 段落结构：每段有主题句；段落长短有变化；过渡自然
- [ ] 图表体例：编号连续、题注中英对照、正文有引用、alt/图例无误标
- [ ] 誊录级数字串核对：正文数字 ↔ 表格数字逐一对照；不一致**转交 S7**
- [ ] 术语/符号全文统一（如 digital twin/数字孪生 混用）
- [ ] 标点规范：中文全角、英文/数字半角；无错别字

## S5 跨学科视角 — 部署/伦理/完整性初筛

- [ ] 动机-验证断层：引言承诺的问题是否都被实验/论证覆盖
- [ ] 部署可行性：成本/时延/数据可得性/人在回路/失效模式
- [ ] 伦理：人类被试/隐私/双重用途；军事·边防类保密与脱敏
- [ ] 相邻领域对话：是否忽视平行领域的成熟方案
- [ ] 数据完整性疑点初筛（异常分布/合成指纹/不可能数值）→ **转交 S7 复算**；
      定性纪律：只可定性「须解释的异常」，不得直接认定造假

## S6 魔鬼代言人 — 反论证与 CRITICAL

- [ ] 最强反论证三条（若要拒稿的理由）
- [ ] 过度声明逐条：结论/摘要/引言中的强度词 vs 证据
- [ ] 选择性报告：不利结果/弱基线是否被隐藏
- [ ] [CRITICAL] 标注触发 Reject 级问题（1d 须逐条专节回应）
- [ ] 外部事实指控先核验后提交（撤回规则约束同样适用）

## S7 数值审计 — 逐数复算（垄断）

- [ ] **先跑 numeric_checks 库**：weighted_identity / table_sums /
      abstract_numbers / percent_basis（checks.json 构造见脚本 --help）
- [ ] 手工扩展论文特有不变量（Monte-Carlo 核对/跨表勾稽/量纲口径）
- [ ] 对照 PDF 原表（tex/docx 源用 PyMuPDF find_tables 抽表或渲染页图核对；
      转换丢失 table* 时以编译 PDF 为准）
- [ ] 每条数值发现附复算表（| ID | 检查 | 标签 | 复算值 | 稿件值 | Δ | 判定 |）
- [ ] 承接 S2/S4/S5 转交的数值疑点，1c 数值争议由本席裁定
- [ ] 不做定性批评（方法论→S2，声明强度→S6）

## 维度0：去AI化检查（阶段2 专用，各审计代理基础清单）

- [ ] 无 Tier1 词汇（delve, landscape, tapestry, paradigm shift, leverage, harness, navigate, realm, embark, myriad, plethora, multifaceted, groundbreaking, revolutionize, synergy, ecosystem, resonate, streamline）
- [ ] 无过度对仗（「从X到Y」「不仅X更Y」密集）；无排比式列举
- [ ] 无空洞总结（「综上所述」「总而言之」每段使用）
- [ ] 无AI高频词过度使用（核心/关键/本质/范式）
- [ ] 句式长短交错
- [ ] **英文摘要专检**（v2.0 决策⑩）：机译痕迹（悬垂/杂糅，如「Aiming The…」）、
      中英摘要术语一致性、全半角标点、Tier1 词汇

## 严重度分级对照（与 merge_findings.py 一致）

| 级别 | 含义 | 典型问题 |
|------|------|---------|
| **P0** | 必须修改 | 事实错误、数值错误（S7 复算证实）、引用错误（与原文不符/过度延伸）、逻辑断裂、过度声明、保密/伦理缺失 |
| **P1** | 重要修改 | AI痕迹声称级、结构问题、术语错误、定量断言无源（置换后检查）、可行性论证缺失 |
| **P2** | 建议修改 | 措辞润色、语句打磨、标点、错别字、AI痕迹语言级、程序性缺项（致谢等） |
