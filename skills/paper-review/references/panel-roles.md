# panel-roles.md — 合并同行评审面板：七席章程（v2.0）

> **可替换模板**：本文件按论文类型/学科定制（调整席位检查清单），无需修改 SKILL.md 核心流程。
> 使用方：paper-review 阶段1（正式模式 Workflow 多代理 与 --quick 单实例扮演 均依据本文件）。
> v2.0 取代 agent-roles.md：原阶段2 五角色（A1–A5）与原阶段3 ars-reviewer 视角合并为七席，
> 职责边界互不重叠；辩论-撤回机制与编辑决议信两侧独占产出均保留。

## 总则

- 七席并行、**互盲**独立审查（1b），禁止交叉沟通；讨论只发生在 1c（主持人组织）
- **IRON RULE**（每席 prompt 必须注入）：只读审查，不得修改被审稿件；批评必须到行号/段落；
  优缺点平衡（每席至少列 1 条优点）；评分必须有据
- 每条发现：**严重度 [P0]/[P1]/[P2] + 位置（§X.Y 第N段/行号）+ 问题 + 建议 + 原句引文（≥15字）**
- 严重度定义：P0 必须修改（事实/引用/逻辑/数值错误、过度声明）；P1 重要修改
  （结构、术语、AI痕迹声称级）；P2 建议修改（措辞、标点、誊录）
- 结构要素核查（缺摘要/缺参考文献等）**仅 S1 执行**；数值复算**仅 S7 执行**（垄断规则见各席）
- 共同豁免清单（1a 配置卡统一下发，各席不得重复上报）：
  学位文体、期刊模板格式、pandoc/PDF 转换伪影（见 conversion_audit.md 丢失清单）、
  「文献[N] XXX」逐篇引用平行句式（学报标准风格）
- doctype 准则绑定：各席按 config.json 的 applied_criteria 执行必备/豁免/置换规则
  （见 doctype-criteria.md）；类型不符证据走「类型适配异议」（单条，交主持人仲裁），
  不得自行按另一套基准散报

## 输出格式（每席统一，500–800字）

```markdown
## [席位名] 评审报告

### 总体评价
（1–2句概括 + 至少1条优点）

### 主要发现
1. [P0] 位置：§X.Y 第N段
   问题：…
   引文：「…（≥15字原句）」
   建议：…
2. …

### 评分
方法论: N/10 | 写作: N/10 | 创新性: N/10 | 总体: N/10
```

## S1 EIC/统筹（原A5+原EIC）

**职责边界**：选题价值/贡献清晰度/结构闭环/规范完整性/决议档位建议；**不深入公式与统计**。

**垄断规则——结构检查垄断 + 类型适配判定**：
- 结构要素核查（摘要/参考文献/实验节/结论/致谢/声明页…）仅由本席执行，按 doctype
  准则出具「类型适配判定」：必备缺失→按准则严重度上报；豁免缺失→报告头「类型适配说明」
  一句话注明，不计入 P0/P1/P2
- 其余各席遇结构缺失**引用 S1 判定，不得重复上报**
- 合规清单组核查（保密审查/伦理声明/AI 使用披露/数据可得性）归本席

**检查清单**：
- [ ] 核心贡献是否清晰、与标题/摘要一致
- [ ] 引言→正文→结论结构闭环
- [ ] 结构要素按 doctype 准则逐项核查（必备/豁免/合规）
- [ ] 决议档位建议（Accept/Minor/Major/Reject）及理由

## S2 方法论（原A1+原R1）

**职责边界**：研究设计/统计有效性/可复现性/实验公平性；**不做逐表复算**（交 S7）。

**检查清单**：
- [ ] 每个论点是否有充分证据支撑；因果推理是否跳跃；是否循环论证
- [ ] 统计方法是否恰当（检验选择/样本量/效应量/显著性表述）
- [ ] 实验设置是否公平（基线/消融/对照）；结论是否超出证据范围
- [ ] 可复现性：实现细节/超参数/数据划分是否充分（按 doctype 置换规则）

## S3 领域（原A2+原R2）

**职责边界**：文献谱系/溯源核实（可联网）/术语共识/增量定位。
**v2.0 拆分**：引文**格式**检查已脚本化（bib_lint.py，S3 不再手工查格式）；
S3 只做**语义核对**——引用描述与原文是否相符（联网或原文对照）、是否过度延伸、
是否遗漏关键文献。

**检查清单**：
- [ ] 引用描述与被引原文一致（逐条抽查高危引用：支撑核心论断者必查）
- [ ] 是否遗漏领域重要文献；增量定位是否诚实
- [ ] 术语使用与领域共识一致；跨领域映射是否合理
- [ ] bib_lint.md 中标记 error 的条目：仅复核脚本判定，不重复扫描

## S4 写作编辑（原A3）

**职责边界**：句式/图表体例/标点/誊录级数字串核对/术语统一。
**唯一承接原阶段2独占产出**的席位（细粒度语言/体例发现）。

**检查清单**：
- [ ] 连续相同句式/对仗排比（AI痕迹语言级，与阶段2去AI重叠时以阶段2为准）
- [ ] 图表体例：编号连续、题注中英对照、正文有引用
- [ ] 誊录级核对：正文提及的数字串与表格逐一对照（发现不一致**转交 S7 复算**，
      不自行定性）
- [ ] 术语/符号全文统一；标点全半角规范

## S5 跨学科视角（原R3）

**职责边界**：部署可行性/伦理与人在回路/动机-验证断层/相邻领域对话/
**数据完整性疑点初筛**。

**检查清单**：
- [ ] 动机（引言承诺）与验证（实验覆盖）之间是否存在断层
- [ ] 部署可行性：成本/时延/数据可得性/人在回路
- [ ] 伦理：人类被试/隐私/双重用途（军事·边防类注意保密与脱敏）
- [ ] 数据完整性疑点初筛（异常分布/合成指纹/不可能的数值模式）→ 提交 S7 复算
      与主持人裁定；**定性纪律**：合成指纹类指控只可定性为「须解释的异常」，
      不得直接认定造假（见报告模板「数据完整性关切」节）

## S6 魔鬼代言人（原A4+原DA）

**职责边界**：最强反论证/选择性报告/过度声明；CRITICAL 标注；**专属报告格式保留**。

**检查清单**：
- [ ] 最可能被审稿人攻击的弱点是什么（逐条列出）
- [ ] 过度声明（over-claiming）：结论强度 vs 证据强度
- [ ] 选择性报告：不利结果/基线是否被隐藏
- [ ] CRITICAL 标注：认为足以触发 Reject 的问题必须标 [CRITICAL]，
      且**每条 CRITICAL 在 1d 综合中有逐条专节**（铁律）

**专属输出格式**（在统一格式之上追加）：

```markdown
### 最强反论证
（若我要说服编委会拒掉这篇论文，我的三条理由）

### CRITICAL 清单
- [CRITICAL] 位置：… 问题：… 引文：「…」
```

**证据纪律**：涉及外部事实的指控（文献内容/数据集规模/他文结论）必须先完成
文献级核验（联网或原文对照）才可提交；核验不成立自行撤回并留「撤回记录」
（见 discussion-protocol.md 撤回规则）。

## S7 数值审计（v2.0 新专席）

**职责边界**：**逐数复算**；不做定性批评（方法论批评归 S2，声明强度归 S6）。

**垄断规则——数值复算垄断**：任何席位对数字的怀疑（S4 誊录不一致/S5 完整性疑点/
S2 统计疑点）一律转交 S7 复算裁定；1c 讨论中**数值类争议强制交 S7**，主持人不自行裁数。

**工作流程（章程）**：
1. **先跑数值检查库**（scripts/numeric_checks/）：构造 checks.json
   （weighted_identity / table_sums / abstract_numbers / percent_basis 四检查器），
   机器核查表为复算基础
2. 再手工扩展论文特有不变量（Monte-Carlo 核对、跨表勾稽、量纲/口径一致性）
3. 对照 PDF 原表：源为 tex/docx 时用 PyMuPDF 抽表（find_tables）或渲染页为 PNG
   后 Read 图像核对（转换丢失 table* 时以此为准，见 conversion_audit.md）
4. **每条数值类发现必须附「复算表」**（库输出或手写复算片段），格式：

```markdown
| ID | 检查 | 标签 | 复算值 | 稿件值 | Δ | 判定 |
|----|------|------|--------|--------|---|------|
| R-1 | weighted_identity | 表3.1 综合分 | 66.54 | 69.11 | -2.57 | fail |
```

**检查清单**：
- [ ] 加权/综合分恒等式（分项×权重 = 总分）
- [ ] 跨表一致性（同一指标在多表出现时数值一致）
- [ ] 摘要数字 ↔ 正文表格交叉（含「摘要零数字」警示）
- [ ] 百分比 vs 百分点口径、分母口径
- [ ] 行列和勾稽、均值/方差复算
- [ ] Monte-Carlo/仿真结果的可复现抽样核对（如适用）

## --quick 模式席位映射

`--quick` = **S1+S6 两席**单实例扮演 + 跳过讨论轮（1c）：S1 出结构/类型适配/决议建议，
S6 出最强反论证；数值疑问记入发现并标注「未复算（quick 模式）」，不派 S7。

## 评分与决议

- 每席报告末尾附四维评分（方法论/写作/创新性/总体，各 N/10）
- 评分汇总取七席四维均值 + 主持人综合；Decision 映射评分保留：
  Accept=9 / Minor Revision=8 / Major Revision=6 / Reject=4
- 严重度分歧仲裁记录保留；未决分歧交用户裁决（机制不变）
