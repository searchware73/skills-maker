# doctype-criteria.md — 稿件类型准则绑定表（v2.0 §八）

> **可替换模板**：每种稿件类型三组规则（必备/豁免/置换）+ 合规清单组。
> **机器可读版内嵌于 setup_env.py 的 `DOCTYPE_CRITERIA` 字典（唯一权威源），
> 两处必须同步修改**；setup_env.py 输出的 `applied_criteria` 即本表的运行时快照。
> 实证来源：q10 案（problem-collection 被按 full-paper 审，「零参考文献」被多席
> 误报 P0，只能手工声明「本次忽略」清单——类型缺失的症状）。

## 使用规则（全席位强制）

1. **声明**：Step 0 `--doctype` 显式声明；未声明时技能必须 AskUserQuestion 确认
   （附 setup_env.py 的自动检测线索 doctype_hints），**禁止按默认 full-paper 臆测**
2. **垄断**：结构要素核查仅由 **S1（EIC）** 执行并出具类型适配判定；
   其余各席遇结构缺失引用 S1 判定，不得重复上报（与 S7 数值垄断同构）
3. **豁免呈现**：豁免要素缺失一律不作为发现上报；报告头「稿件类型与准则适配」节
   每缺席项一句话注明（不计入 P0/P1/P2 统计）
4. **置换不是放松**：置换规则是把检查换成该类型**正确**的检查，严重度照报
5. **异议**：类型与内容实质不符 → 走「类型适配异议」单条争议（discussion-protocol.md），
   主持人仲裁换类型（重绑准则、补跑受影响检查）或维持+报告注明
6. **继承**：re-review 自动继承上一轮 doctype 与豁免清单（config.json）

## 类型枚举

`full-paper | thesis | proposal | problem-collection | extended-abstract |
technical-report | section-draft | review | other:<描述>`

## 逐类型准则

### full-paper（完整论文，期刊/会议）

| 组 | 内容 |
|----|------|
| 必备 | 摘要（缺=P1）；参考文献（缺=**P0**）；实验/数据支撑（缺=P0）；结论（缺=P1） |
| 豁免 | （无） |
| 置换 | （无——全检查适用：统计审查/可复现性/引用检查） |
| 合规 | 数据/代码可得性声明；AI 使用披露；人类被试/数据伦理声明（涉及时） |

对照示例：仿真稿件-20261105（期刊稿，full-paper，Major + Reject 触发
+「数据完整性关切」专节）。

### thesis（学位论文）

| 组 | 内容 |
|----|------|
| 必备 | 中英文摘要（缺=P1）；参考文献（缺=P0）；致谢（缺=**P2 程序项**）；独创性声明页（缺=P2） |
| 豁免 | （无） |
| 置换 | （无） |
| 合规 | AI 使用披露（he-paper 正例：5 项用途逐一披露获正面认定）；保密审查/地名脱敏声明（涉及时） |

注意：学位文体（长铺垫、章节小结）在共同豁免清单内，不按期刊文风报 AI 痕迹。
对照示例：li-paper-v13（学位论文，Minor）。

### proposal（立项申报/开题）

| 组 | 内容 |
|----|------|
| 必备 | 定量断言出处（缺=P1）；可行性论证（缺=P1） |
| 豁免 | 摘要；参考文献；实验节；统计审查；可复现性 |
| 置换 | 「数据支撑证明」→「**声称↔依据**」（preliminary data / 权威出处 / 可行性论证，参照 academic-humanizer Layer 6 的 claim↔feasibility 纪律）；「引用检查」→「支柱性定量断言须注明数据来源，叙述性背景可无引用」 |
| 合规 | 保密审查/地名脱敏声明（军事·边防类） |

### problem-collection（问题征集/需求清单）

| 组 | 内容 |
|----|------|
| 必备 | 定量断言出处（缺=P1）；问题遴选方法说明（缺=P2） |
| 豁免 | 摘要；**参考文献**；实验节；统计审查；可复现性；结论节 |
| 置换 | 同 proposal（声称↔依据；支柱性定量断言须注明数据来源） |
| 合规 | 保密审查/地名脱敏声明（军事·边防类） |

**q10 案在 v2.0 下的预期行为（对照示例）**：
声明 `--doctype problem-collection` →
- 「零参考文献」**不入报告**（头部一句类型说明：「problem-collection 类型豁免参考文献」）
- 「定量指标无源」以置换后的「定量断言出处」检查报 **P1**
- 「题文不符/缺遴选方法」作为**内容发现正常保留**（类型绑定只豁免结构类检查，
  不豁免内容质量）
- 复审轮自动继承，无需手工「本次忽略」清单

### extended-abstract（长摘要/扩展摘要）

| 组 | 内容 |
|----|------|
| 必备 | 核心贡献陈述（缺=P1） |
| 豁免 | 独立摘要节；参考文献；结论节；统计审查 |
| 置换 | （无） |
| 合规 | （无） |

### technical-report（技术报告）

| 组 | 内容 |
|----|------|
| 必备 | 数据来源说明（缺=P1） |
| 豁免 | 摘要；参考文献 |
| 置换 | 「可复现性」→「实现环境描述完整性」 |
| 合规 | 数据/代码可得性声明 |

### section-draft（章节草稿）

| 组 | 内容 |
|----|------|
| 必备 | （无——只审内容质量） |
| 豁免 | 摘要；参考文献；结论节；结构完整性（全豁免） |
| 置换 | （无） |
| 合规 | （无） |

### review（综述）

| 组 | 内容 |
|----|------|
| 必备 | 参考文献·覆盖度（缺=P0）；文献谱系梳理（缺=P1）；摘要（缺=P1）；结论与展望（缺=P1） |
| 豁免 | 实验节；可复现性 |
| 置换 | 「统计审查」→「文献计量口径一致性」 |
| 合规 | AI 使用披露 |

### other:<描述>

无预置准则。1a 配置卡阶段由 S1 依用户描述**现场出具类型适配判定**，
必备/豁免要素经 AskUserQuestion 与用户确认后写入 config.json（下轮继承）。

## 合规清单组（按类型绑定，S1 核查，缺项按类型定级；类型未要求的不报）

| 合规项 | 适用 | 缺失定级 |
|--------|------|---------|
| 保密审查/地名脱敏声明 | 军事·边防类（proposal/problem-collection/full-paper 涉及时） | P0（仿真稿件 P0-9 案） |
| 人类被试/数据伦理声明 | 医疗·用户数据类 | P0 |
| AI 使用披露 | full-paper/thesis/review | P2（期刊有硬性要求时升 P1） |
| 数据/代码可得性声明 | full-paper/technical-report | P2 |
