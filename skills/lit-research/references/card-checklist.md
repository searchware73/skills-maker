# 卡片验证清单 V1–V6（card-checklist.md）

每篇新建卡片入库前逐项核对。`validate_card.py` 做机械检查，本清单同时约束人工复核部分。任一验证点不通过 → 回退到对应步骤修复 → 重跑验证，直至全部通过。

## V1 调研流程完整性

- [ ] deep-research (full级) 已实际调用并完成
- [ ] 检索/查重/评价无跳过、无降级

## V2 查重无遗漏

- [ ] 所有候选已用 lookup_lib.py 比对
- [ ] 4信号查重（标题/DOI/arXiv/作者+标题）已执行
- [ ] 二次人工复核已完成
- [ ] 无"已在库却当新候选"的误判

## V3 卡片格式

- [ ] 9个基本信息字段齐全且顺序正确（编号/作者/标题/年份/类型/出版源/DOI-URL/引用方式/验证状态）
- [ ] 编号与目录名、文件名前缀一致
- [ ] 摘要为原文逐字摘录 + 中文翻译 + 来源标注
- [ ] 引用方式符合 GB/T 7714 格式（见 gbt7714-quickref.md）

## V4 内容概要

- [ ] 字数在 800-1000 范围
- [ ] 结构：背景/问题 → 核心内容(方法→实验→结论) → 与主题的关联
- [ ] 事实在前、评价殿后（铁律）
- [ ] 忠于原文，不臆造、不过度延伸
- [ ] 末尾有依据标注

## V5 去AI化

- [ ] /stop-slop 已实际运行
- [ ] /academic-humanizer 已实际运行
- [ ] /humanize-writing 已实际运行
- [ ] 无 Tier1 词汇（delve/landscape/tapestry/paradigm shift/leverage等）
- [ ] 无过度对仗结构
- [ ] 无空洞总结性语句

## V6 入库集成

- [ ] 目录命名 NNN_XXX/ 正确
- [ ] 文件名前缀 NNN_ 与编号一致
- [ ] 卡片/提取/源文件三件套齐全
- [ ] 文献库索引已重建且包含新条目

## 使用说明

- 机械项由 `validate_card.py --number NNN --lib-path <库路径> --extract-log <去AI日志>` 自动检查（V1–V6 输出 JSON）。
- 人工项（V1 无降级、V2 二次复核、V4 忠于原文、V5 三项文字特征）由执行者对照 extract 原文逐条核对后在报告中声明。
- 去AI日志 `_step7_deai_log.txt`：每实际运行一个去AI技能，追加一行「时间 + 技能名 + 处理文件」。
