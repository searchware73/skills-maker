# 文献质量评分细则（quality-rubric.md）

对每篇净新候选文献按 5 个维度打分（每维 1–5 分，满分 25），据此决定是否建卡入库。评分须基于 deep-research 报告与实际核查，不得凭印象打分。

## 一、五维度评分表

| 维度 | 5 | 4 | 3 | 2 | 1 |
|-----------|---|---|---|---|---|
| 主题相关度 | 直接匹配研究主题 | 高度相关，核心子领域 | 部分相关，外围领域 | 弱相关，仅方法论借鉴 | 无关 |
| 来源可信度 | 顶刊(SCI Q1/CCF-A/Nature/Science)或权威机构报告 | 良刊(SCI Q2/CCF-B) | 一般期刊(Q3-Q4)或普通会议 | 预印本但有已发表版本 | 非正式来源/博客/未审稿 |
| 方法严谨性 | 方法完整、可复现、验证充分 | 方法清晰但有小缺陷 | 方法基本可用但描述不充分 | 方法模糊或缺乏验证 | 方法有明显缺陷 |
| 时效性 | 2年内发表 | 5年内发表 | 5-10年经典文献 | 10年以上历史文献 | 已过时/被取代 |
| 引用价值 | 必引经典/开创性文献 | 高价值，重要支撑 | 可选支撑材料 | 低价值，仅背景参考 | 无引用价值 |

## 二、决策矩阵

| 总分 | 决策 |
|------|------|
| ≥20 | 强推荐建卡 |
| 15–19 | 推荐建卡 |
| 10–14 | 有充分理由时建卡 |
| <10 | 建议跳过 |

> 10–14 分段须在提交用户决策时写明「建卡的充分理由」（如填补某节覆盖空白、唯一系统综述等）。

## 三、加分 / 减分项

在 5 维总分基础上叠加（结果仍以 25 分封顶、0 分保底）：

| 条件 | 调整 |
|------|------|
| 引用次数 > 1000 | +1 |
| 获最佳论文奖 | +1 |
| 系统综述 / Meta 分析 | +1 |
| 已撤稿 | −2 |
| 与库中已有文献高度重复 | −2 |

## 四、评分记录格式

评分结果写入 `_step4_scores.json`，每篇一条：

```json
{
  "title": "...",
  "scores": {"relevance": 5, "source": 4, "rigor": 4, "timeliness": 5, "value": 4},
  "adjustments": [{"reason": "系统综述", "delta": 1}],
  "total": 23,
  "decision": "强推荐建卡",
  "note": ""
}
```

## 五、纪律

1. **宁缺毋滥**：不刻意凑数；低分候选如实报告并建议跳过。
2. **重复即减分**：与库内文献高度重复（同一工作的预印本/正式版、同组近重复综述）按 −2 处理，并在查重环节（lookup_lib.py）已拦截者优先以查重结论为准。
3. **评分留痕**：所有分数与加减分理由必须写入 `_step4_scores.json`，供用户决策与事后复核。
